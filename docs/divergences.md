# Divergences from `mrp`

Every known difference between a transpiled run and `mrp`. Each one is an entry
of the allowlist [`test/e2e/divergences.json`](../test/e2e/divergences.json),
and the table below is generated from it (`make docs-divergences`).

## How the allowlist works

The differential tests (`TestMrpDiff`, `TestMrpDiffFailureParity` and the
golden suites) excuse a difference only through an entry's matcher. So a
difference no entry matches fails a test, and removing an entry fails the case
it matched.

| Kind | Excuses |
|---|---|
| **abi** | a difference in a stage's `_args` or `_outs` |
| **published-tree** | a difference in the published `results/` tree or `pipeline_outs.json` |
| **outcome** | a difference in how a run ends |
| **mechanism** | nothing: it records a difference in *how* mro2nf reaches `mrp`'s outputs that leaves them identical, so it has no matcher and cites the tests that prove the outputs match |

An entry with an issue lasts until the issue is fixed. Unless its matcher is an
outcome, which fails its case once mro2nf matches `mrp`, it is scoped to the
fixtures where it must excuse a difference, applies only there, and fails each
of them where it no longer does. A permanent entry is intentional and applies
on every fixture.
